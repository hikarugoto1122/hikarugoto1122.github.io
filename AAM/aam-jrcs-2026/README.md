# JRCS 2026: accepted manuscript and research materials

This folder contains files associated with the following article:

> Goto, H. (2026). Framing the attitude-behavior gap as structural disconnection: A dual-level diagnostic of customer experience quality. *Journal of Retailing and Consumer Services, 92*, 104814. https://doi.org/10.1016/j.jretconser.2026.104814

## Files

- `aam-jrcs-2026.pdf`: Author Accepted Manuscript. This is not the Version of Record. The manuscript contains the applicable CC BY-NC-ND 4.0 notice and a link to the published version.
- `df.csv`: analysis data used by the revision script (532 observations).
- `Rcode_dfcsv_revision.R`: R script for the CFA, SEM, and psychological network analyses reported during revision. Run the script with `df.csv` in the working directory.

Please cite the published article when using these materials. No separate license has been specified for `df.csv` or `Rcode_dfcsv_revision.R`.
